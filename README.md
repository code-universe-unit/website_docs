# GreenCom Mapping Wiki

Official documentation website for GreenCom Mapping MLO projects built with VitePress.

🌐 **Live Site**: https://docs.greencom-maps.com

## 🚀 Quick Start

### Development

```bash
npm install
npm run dev
```

Visit `http://localhost:5173` to see the site.

### Build

```bash
npm run build
```

### Preview Build

```bash
npm run preview
```

## 📁 Project Structure

```
docs/
├── .vitepress/
│   ├── config.ts          # VitePress configuration
│   └── theme/             # Custom theme
├── mlo/                   # MLO Projects documentation
│   ├── logistic-company-v2.md
│   └── mc-clubhouse-grapeseed.md
├── public/                # Static assets
└── index.md              # Homepage
```
